Android and Windows support / Soporte Android y Windows

Added 5 November 2026 · Añadido el 5 de noviembre de 2026.

The Android and Windows editions use local game resources and local saves. Android preparation requires Android 7.0 or later and a functioning Android System WebView. This notice does not announce a public release or prove that your device has been tested.

Use the game’s touch controls on Android. On Windows use the existing keyboard or pointer controls described above.

Try closing and reopening the app first. Clearing data or reinstalling can remove local saves. For help, send only the app version, Android or Windows version and a short description to coderappskrazel@gmail.com.
