Android and Windows support / Soporte Android y Windows

Added 5 November 2026 · Añadido el 5 de noviembre de 2026.

The Android and Windows editions use local game resources and local saves. Android preparation requires Android 8.0 or later and a functioning Android System WebView. This notice does not announce a public release or prove that your device has been tested.

Use the on-screen book and placement controls. Android uses touch; Windows uses the pointer.

Try closing and reopening the app first. Clearing data or reinstalling can remove local saves. For help, send only the app version, Android or Windows version and a short description to coderappskrazel@gmail.com.

Android use and purchase information / Información de uso y compras Android

Las ediciones de Android y Windows usan recursos y partidas locales. La preparación Android requiere Android 8.0 o posterior y Android System WebView operativo. Este aviso no anuncia una publicación pública ni acredita pruebas en tu dispositivo.

Usa los controles de libros y colocación de la pantalla. Android usa interacción táctil y Windows el puntero.

Prueba primero a cerrar y abrir la app. Borrar datos o reinstalar puede eliminar partidas locales. Para recibir ayuda, envía solo la versión de la app, la versión de Android o Windows y una descripción breve a coderappskrazel@gmail.com.
